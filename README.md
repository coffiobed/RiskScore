# RiskScore
: A l’aide de la régression logistique sur le logiciel R j’ai développé un modèle prédictif de risque de crédit à partir des données historiques de 20 000 clients prises sur Kaggle déterminant le résultat binaire de l'approbation d’un prêt en indiquant si un demandeur est susceptible d'être approuvé ou refusé pour un prêt.
